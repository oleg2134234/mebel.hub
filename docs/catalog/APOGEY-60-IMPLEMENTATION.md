# Реализация 60 карточек Apogey

Дата контрольной точки: 01.10.2026.

Этот файл — переносимая точка продолжения проекта. Он хранится в ветке `codex/apogey-60-cards` и обновляется после каждой рабочей партии, чтобы работу можно было продолжить с другого компьютера без привязки к локальной сессии.

## Цель

Добавить в каталог 60 отсутствующих моделей Apogey:

- 31 диван;
- 3 кресла;
- 23 кровати;
- 3 матраса.

Для каждой модели создаётся отдельная карточка с 1–2 слайдами:

1. Основное официальное фото или согласованная интерьерная визуализация Syntx по официальному референсу.
2. Официальная схема размеров, если производитель опубликовал её для конкретной модели и комплектации.

## Как продолжить с другого компьютера

```powershell

cd mebel.hub
git fetch origin
git switch --track origin/codex/apogey-60-cards

```

Если репозиторий уже клонирован:

```powershell

```

Не использовать `git reset --hard` и не переносить в ветку случайные локальные изменения с другого компьютера.

## Рабочий цикл карточки

1. Открыть строку модели на листе `Не хватает` и карточку производителя.
2. Проверить название, категорию, габариты и соответствие размерных вариантов.
3. Скачать официальное фото конкретной модели; не использовать похожий товар.
4. Для первого слайда использовать официальное фото либо утверждённую визуализацию Syntx.
5. Добавить второй слайд только при наличии официальной схемы размеров нужной комплектации.
6. Назначить новый уникальный локальный ID после проверки текущего максимального ID.
7. Добавить карточку в `PRODUCTS`, обложку в `IMAGES`, галерею в `GALLERIES`.
8. Проверить поиск, категорию, фильтры, прямую ссылку `?product=<id>` и оба слайда.
9. Запустить `node tools/audit-catalog.js` и `git diff --check`.
10. Обновить таблицу прогресса ниже, закоммитить и отправить готовую дневную партию в эту ветку.

## Правила Syntx

- Syntx применяется только для первого слайда; схема размеров не генерируется.
- Официальное фото конкретной модели обязательно используется как референс.
- До первого платного запуска согласовать точный промпт, модель, формат, разрешение, стоимость и лимит партии.
- Сначала сделать один тест. Не запускать оставшуюся партию, пока тест не проверен по форме, модулям, подлокотникам, подушкам, швам, опорам, цвету и фактуре.
- На первом проходе — максимум одна генерация на карточку. Повторные варианты требуют отдельного согласования расхода.
- Не хранить токены, ключи, cookies и другие секреты в репозитории.

## Ежедневная фиксация

В конце рабочего дня:

```powershell
node tools/audit-catalog.js
git diff --check
git status --short
git add -- docs/catalog/APOGEY-60-IMPLEMENTATION.md docs/catalog/PLAN.md index.html assets/<готовые-модели>
git commit -m "feat: add Apogey catalog batch day N"
git push origin codex/apogey-60-cards
```

Перед `git add` заменить `<готовые-модели>` точными путями и проверить, что в индекс не попали посторонние файлы. Публикация в `main` и на GitHub Pages выполняется отдельно, только после явного согласования готовой партии.
