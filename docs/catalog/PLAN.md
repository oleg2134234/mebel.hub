## Приёмка каждой карточки

- [ ] Размеры и комплектация имеют источник и дату.
- [ ] Один узнаваемый предмет на всех слайдах; цвета и варианты подписаны.
- [ ] Товар крупный, целиком, без деформаций и лишнего окружения.
- [ ] Размерная схема соответствует реальному сложенному и разложенному состоянию.
- [ ] Новый слайд «Преимущества и особенности» содержит только проверенные факты.
- [ ] Фильтры и подписи согласованы.
- [ ] audit-catalog.js и git diff --check; просмотр браузера.
- [ ] Журнал заполнен; карточка показана пользователю.
