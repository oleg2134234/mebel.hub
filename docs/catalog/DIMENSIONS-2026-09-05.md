Бруно: пользователь явно одобрил показанный вариант удаления фона («вариант удаления фона супер»). Исходники обработки сохранены как dims-folded-white-v1.png и dims-unfolded-white-v1.png. Это обработка фотографий, а не точное сохранение исходных пикселей. Силуэт, конструкция, число модулей, подголовники, подлокотники, состояние раскладки и обе петли сверены с исходными кадрами.

Финка: оригинальные JPEG из галерей встроены в SVG без изменения и повторного кодирования. Размерные линии — векторные, с одинаковым нормальным смещением обоих концов относительно выбранной грани. Панели собраны отдельно, затем объединены вертикально. Скрипты воспроизведения: tools/render-finka-dimensions.js и tools/render-bruno-dimensions.js.

Остин 3 ДК: из галереи удалена только ссылка на assets/ostin-3-dk/slide_angle2.jpg; исходный файл сохранён.

Пользователь отдельно одобрил итоговые слайды 233 («финка 5 дк отлично») и 234 («Финка 4.1 ДКУ супер»). Итоговые версии трёх Финок — slide_dims-v3.svg; проверены в полных карточках локального каталога. Предпочтение по дальнейшей обработке уточнено: imagegen удаляет фон, SVG собирает панели и выноски.
