## Как работает конвейер
1. `fetch.mjs` — выгрузка данных API apogey-mebel.ru → `all.json` (в C:\Temp\claude\work; пересоздаётся).
2. `rows.txt` → `mkcards.py` → `cards.json` (id, название, dims, описание, подпись, цвет).
3. Syntx: во встроенном браузере Claude (вкладка логина syntx.ai/ru/image/banana), `setup.js` кладёт в страницу карту референсов и функции `gen/run`; референсы тянутся с admin.apogey-mebel.ru прямо со страницы. `run(id)` создаёт новый чат, грузит 2 референса, вставляет промпт и отправляет (−2 токена).
4. `getgen.sh id webId url` — скачивает результат, делает `gen/<id>.jpg` и картинку сравнения; проверять глазами по правилу идентичности (форма, число секций, сторона оттоманки, цвет). Если зеркально — отразить по горизонтали.
5. `pub.sh id` — карточка в `PRODUCTS/IMAGES/GALLERIES` рабочей копии + коммит; `push.sh` — публикация пачкой (по просьбе пользователя — после каждых 5 генераций).
