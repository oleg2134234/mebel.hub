# Слайд «Уют» для 57 карточек Apogey

Состояние на 03.10.2026: **все 57 карточек готовы и опубликованы** (34 дивана/кресла + 23 кровати). Три матраса (295, 299, 300) пропущены по решению пользователя. Навык нужен для перегенерации слабых кадров (список замечаний — в `docs/catalog/CHANGELOG.md`, запись 02–03.10.2026: 310, 297, 318, 320, 292, 293, 274, 301) и для новых карточек по тому же образцу. Сначала прочитай `CLAUDE.md` (правило № 1 — идентичность модели) и раздел «Как делать слайд «Уют»».

**Перегенерация готового слайда:** `cozy_pub.py` пропускает карточку, у которой «Уют» уже есть («уже есть слайд»). Для замены — вручную подменить файл `assets/<slug>/slide_cozy.jpg` (1400 px JPEG q86) и при необходимости подпись.

**Лимит Syntx: одна активная генерация за раз.** Запуск следующего кадра, пока идёт предыдущий, оставляет в чате неотправленный черновик (баланс не списан): дождаться готовности (≈1–2 мин, проверять `location.reload()`/адрес чата), затем в этом же чате вызвать `document.querySelector('button.send-actions__send').click()` или запустить карточку заново.

## Правила пользователя
- Слайд «Уют» — **вторым** (после «В интерьере»; «Размеры» сдвигаются на 3-е место).
- Формат **4:3 горизонтальный** (Syntx Nano Banana Pro, 2K, 2 токена за кадр); мебель **целиком в кадре, без обрезания** (≈55–60 % ширины, поля ≥18–20 % слева и справа).
- На каждом слайде **свой интерьер** (разные стили, но сочетающиеся с цветом мебели), **свой сюжет и ракурс**, **люди сидят в разных местах** (край, середина, оттоманка, пол перед диваном, лёжа). Люди — мужчины, женщины, дети, иногда двое; питомцы — кошки, кролики, собаки, попугаи, морские свинки.
- **Плед и сюжет «питомец на пледе» не использовать**; не только «читает книгу».
- Идентичность важнее всего: цвет, число секций, сторона оттоманки, узор изголовья. Гладкое изголовье не превращать в стёганое; чужой диван — отклонить и повторить с описанием конструкции (`SOFA_DETAIL`/`DETAIL`).
- Без логотипов (в том числе на ноутбуках, телефонах, наушниках).
- Публикация в `main` **после каждых 5 принятых слайдов**. Syntx входит пользователь.

## Файлы (`tools/apogey60/`)
- `cozy_build.py` — данные всех 57 карточек (цвет по фото, интерьер под цвет, замки на изголовья). `python cozy_build.py` → `cozy-cards.json` + `cozy-lib.js`; `python cozy_build.py patch ID …` → JS-патч для консоли Syntx.
- `cozy_scenes.py` (кто/сюжет/питомец по таблице `SC`), `cozy_custom.py` и `cozy_custom2.py` (индивидуальные сюжеты с местом и ракурсом `CUSTOM`, замки конструкции `SOFA_DETAIL`). **У кроватей индивидуальных сюжетов ещё нет** — перед запуском написать их в `cozy_custom3.py` (формат `id: (полный сюжет, ракурс)`, подключить в `cozy_build.py`): разные места на кровати (у изголовья, в ногах, лёжа поперёк, сидя на краю), ракурсы «с изножья слева/справа», сюжеты не про чтение; для 308 Рица детская — ребёнок 7 лет; односпалки 301, 303, 305, 307 — один человек.
- `cozy-prompt-sofa.tpl.txt`, `cozy-prompt-bed.tpl.txt` — шаблоны промптов (идентичность, ракурс `@VIEW@`, кадр без обрезания, без логотипов).
- `cozy_pub.py <worktree> <папка-с-кадрами> ID …` — кладёт `assets/<slug>/slide_cozy.jpg` (1400 px) и вставляет слайд вторым в `GALLERIES`; `cozy_ru.py` — русские подписи («Тёплый вечер на диване: …»). При новом `who`/`pet` дописать перевод в `cozy_ru.py`.

## Конвейер
1. `git fetch origin`, worktree: `git worktree add -b cozy-pub C:/Temp/claude/pub-cozy origin/main` (если нет); все правки и публикация — в нём.
2. В браузере открыть `https://syntx.ai/ru/image/banana` (пользователь залогинен), проверить: Nano Banana → **Banana Pro**, **4:3**, **2K**.
3. Загрузить в localStorage страницы `cozyLib` (содержимое `cozy-lib.js`) и `cozyPatch` (вывод `cozy_build.py patch …`), затем для каждой карточки: `(0,eval)(localStorage.cozyLib);(0,eval)(localStorage.cozyPatch);await window.cozyRun(<id>)`. Если `sent:false` — повторить; если баланс не списался и чат пустой — запустить заново.
4. Через ~60 с `location.reload()` (или открыть адрес чата) → `…/generated/….jpg` (убрать `_500`), скачать с заголовком User-Agent. Следующий кадр можно запускать, пока готовится предыдущий.
5. Сравнить с референсом (пользовательский референс — первый кадр из `dims-picks*.json`/`setup.js`): цвет, форма, секции, сторона оттоманки, узор, логотипы, обрезание. Брак — не публиковать, повтор с уточнением в `config`.
6. Каждые 5 принятых: бэкап `index.html` (`tar --force-local -czf …/backups/source_<дата>_before-cozy-N.tgz`), `python tools/apogey60/cozy_pub.py …`, проверка порядка «В интерьере → Уют → Размеры», `node tools/audit-catalog.js` (критичных 0; 4 известных предупреждения), коммит с `Co-Authored-By`, `git fetch` + `behind=0`, `git push origin HEAD:main`, через 1–3 мин `https://oleg2134234.github.io/mebel.hub/assets/<slug>/slide_cozy.jpg` = 200 и проверка `GALLERIES` на живом сайте.

## Подводные камни
- Syntx иногда не отправляет первый запрос и отдаёт страницу с задержкой — просто перезагрузить страницу.
- Телевизор в сюжете «смотрят фильм» — только за кадром (иначе стоит за диваном); устройства без логотипов.
- Диван из одного кадра модель может «перерисовать» (стиль интерьера тянет за собой другой диван) — помогает описание конструкции и фраза «not a classic sofa with separate seat cushions…».
- Бэкап `tar` на Windows требует `--force-local`.
