# Карточки серий матрасов mebel.hub

Перед работой прочитай в `CLAUDE.md` раздел «Решения от 25.09.2026: слайды размеров и карточки серий» и общие правила данных каталога.

## Цель

В каталоге одна линейка должна выглядеть как одна сравнительная карточка. При этом каждая модель остаётся самостоятельным товаром с прежним `id`, галереей, главным изображением и участием в подборе.

## Как определить состав серии

1. Выбери товары с общим названием линейки и одной категорией `mattress`.
2. Сверь названия, конструкцию, размеры, высоту и нагрузку по `PRODUCTS` и `GALLERIES`.
3. Не объединяй товары только по похожей фотографии. Название и конструктивная принадлежность должны быть подтверждены.
4. Зафиксируй осмысленный порядок в `memberIds`: базовые варианты перед производными, затем `Лайт`/`NEW`, если пользователь не задал иной порядок.

## Данные серии

Добавь объект в `PRODUCT_SERIES`:

```js
{
  id: "slug",
  title: "Название",
  category: "mattress",
  memberIds: [1, 2, 3],
  description: "Короткое проверяемое отличие линейки.",
  summary: ["Ширина … см", "Высота … см", "Нагрузка … кг"]
}
```

- `id` уникален и стабилен.
- `description` помогает сравнить линейку, но не обещает неподтверждённые лечебные или ортопедические свойства.
- `summary` содержит только общий подтверждённый диапазон серии.
- Короткое имя варианта получается удалением названия серии и суффикса «Матрас».
- В строке каждой модели показывай `Ширина … см · Высота … см · Нагрузка … кг`.
- Все размеры в интерфейсе карточек матрасов показывай в сантиметрах. Ширину бери из второй части `dims`, высоту сначала из `desc`, резервно — из третьей части `dims`; значения из `dims` переводи из миллиметров в сантиметры.
- Если характеристика неизвестна, не додумывай её: сначала найди подтверждённый источник, а при его отсутствии явно покажи, что значение уточняется.

## Поведение интерфейса

- Карточка серии показывает до трёх обложек и общее число моделей.
- До четырёх вариантов видны сразу. Для пяти и более вариантов добавляется раскрытие.
- Клик по варианту вызывает `openGallery(id)` и открывает полную карточку конкретной модели.
- Порядок участников берётся из `memberIds`:

```js
const members = series.memberIds
  .map((id) => ordered.find((item) => item.id === id))
  .filter(Boolean);
```

- Не заменяй эту логику фильтрацией `ordered`: она нарушает заданный порядок вариантов.
- При единственном совпадении поиска показывай обычную карточку модели, а не серию.

## Проверка

1. Проверь синтаксис встроенного JavaScript.
2. Открой локальный каталог и фильтр «Матрасы».
3. Убедись, что число моделей не изменилось, а число карточек уменьшилось за счёт группировки.
4. Проверь названия, ширину, высоту и нагрузку каждой кнопки; убедись, что размеры показаны в сантиметрах.
5. Раскрой длинную серию и открой минимум одну модель из скрытой части.
6. Проверь поиск по названию серии и по названию отдельной модели.
7. Покажи результат пользователю в браузере. Публикуй только по явной команде.
